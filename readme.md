# ISHS WIKI

<img src="https://github.com/gyu0ne/ISHS_Wiki/blob/main/views/main_css/file/ishs-logo.png" width="200" height="200"/>

ISHSWIKI를 위해 개량된 openNAMU 기반 위키 엔진으로, 인천과학고등학교 [ISHS WIKI](ishswiki.xyz)에서 사용되고 있습니다. openNAMU 3.6.0을 기반으로 합니다.

# 사용 방법
## 로그인
* 리로스쿨 계정으로 인증하면 자동으로 회원가입/로그인이 진행됩니다.
* 비로그인 상태에서는 열람만 가능하며, 문서 수정을 시도하면 로그인 페이지로 이동합니다.
## 문서 열람/검색
* 상단 검색창에서 문서명과 문서 내용을 함께 검색할 수 있습니다.
* 사이드바에서 최근 변경 내역과 인기 문서(트렌딩)를 확인할 수 있습니다.
## 문서 편집
* 로그인 후 문서 우측 상단의 편집 버튼으로 나무마크 문법을 사용해 문서를 작성/수정할 수 있습니다.
* 각주, 수식, 관련 문서 표시 등 나무마크 문법을 지원합니다.
## 기타
* 설정에서 다크 모드를 켜고 끌 수 있습니다.
* 로그인 시 자신의 열람 기록을 확인할 수 있습니다.

## 직접 설치해서 실행하기
```
pip3 install --upgrade -r requirements.txt
python3 app.py
```
* Windows: `run_windows.bat` 실행
* Linux: `run_ubuntu.sh` 실행
### Docker로 실행
```
docker build . -t ishs-wiki
docker run -p 3000:3000 -v data:/app/data --name ishs-wiki ishs-wiki
```
